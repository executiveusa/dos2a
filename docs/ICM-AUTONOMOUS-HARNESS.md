# dos A — ICM + GRINIONS autonomous harness

This repository uses ICM for context architecture and GRINIONS for execution governance.

## Rule
One active ICM stage at a time. Workers load the stage contract, only required upstream outputs, relevant stable references, and exact code symbols through JCodeMunch. They do not preload the entire repo or project history.

## 20 stages
00 Truth → 01 Repo reconciliation → 02 Asset curation → 03 Conversion architecture → 04 Copy & positioning → 05 Scroll story → 06 Visual system → 07 Public website → 08 Revenue circuit → 09 La Genio public → 10 La Genio owner → 11 Voice & channels → 12 Owner console → 13 Interactive onboarding → 14 Content & portfolio → 15 Full integration → 16 Desktop/mobile QA → 17 Security/recovery → 18 Production → 19 Owner handoff.

## Autonomous execution
Routine implementation, test failures, CI repair, merge conflicts, review findings, and ordinary deployment issues are repaired without asking the owner to continue. Stop only for GRINIONS stop conditions.

## Release truth
Git/GitHub is canonical release truth. Squash merge only. Post-merge verification is mandatory.
