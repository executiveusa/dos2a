# Owner handoff language policy

Target: understandable by a nontechnical high-school student.

- Mexican Spanish first; complete English parity.
- One idea per sentence where possible.
- Prefer action labels: Ver oportunidades, Preparar cotización, Crear campaña.
- Never require architecture knowledge to complete a task.
- Translate internal terms: CRM → Tus oportunidades; pipeline → Seguimiento; lead → Persona interesada / prospecto; workflow → Paso a paso; agent → La Genio; integration → Conexión; deployment → Publicar una nueva versión.
- Technical detail belongs behind optional “Cómo funciona / How it works”.
- Every lesson starts with what it helps the owner do and ends with one real action to try.
- Use screenshots, diagrams, click-through examples, and short practice before long paragraphs.
