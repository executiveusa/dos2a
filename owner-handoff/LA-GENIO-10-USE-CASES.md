# La Genio — 10 casos de uso / 10 use cases

1. **Qué necesita mi atención hoy / What needs my attention today?** — Prospectos nuevos, seguimientos pendientes, cotizaciones por aprobar y eventos con riesgo.
2. **Convierte mi nota de voz en un brief / Turn my voice note into an event brief.**
3. **Prepara mis seguimientos / Prepare my follow-ups.**
4. **Prepárame una cotización / Prepare a quote for me.** El dueño aprueba precio final y envío.
5. **¿Podemos aceptar este evento? / Can we take this event?** Revisa fechas, recursos y conflictos.
6. **Recupera oportunidades olvidadas / Recover missed opportunities.**
7. **Crea una campaña / Create a campaign.** El envío masivo requiere aprobación.
8. **¿Qué más necesita este evento? / What else does this event need?** Sugiere solo servicios relevantes.
9. **Convierte este evento en contenido / Turn this event into content.** Usa solo fotos y hechos aprobados.
10. **Ayúdame a mover ventas hoy / Help me move sales today.** Devuelve pocas acciones concretas y priorizadas.
