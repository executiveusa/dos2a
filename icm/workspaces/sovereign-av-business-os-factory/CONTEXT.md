# Sovereign AV Business OS Factory — CONTEXT

## Purpose

Create a reusable owner-controlled operating system for audiovisual and event-production companies.

## Reference tenant

`dos A` in Mexico is the first implementation and proving ground.

## Product outcome

A branded public website plus lead/CRM, booking/proposal workflows, client/project operations, content/CMS, governed business agent, owner console, exports, backups, and documented recovery.

## Reuse law

Shared product code stays configuration-driven. Tenant differences belong in brand, services, locations, event types, approval policies, integrations, content, assets, and narrowly scoped adapters.

## Ownership law

The client owns repository, domain, hosting, database, media, content, prompts/policies, exports, backups, and connector credentials. Models, agents, builders, and hosting providers must be replaceable.

## Default build sequence

1. truth / audit / baseline;
2. architecture / repo boundaries;
3. tenant / data / auth foundation;
4. first revenue-critical E2E circuit;
5. core operational workflows;
6. content/CMS;
7. governed agent/tool layer;
8. owner/admin console;
9. public frontend and visual differentiation;
10. integrations;
11. security/reliability hardening;
12. productization/reuse;
13. internationalization when required;
14. final system verification and owner handoff.

## Non-goals for first reusable release

Do not build a general ERP, payroll, tax filing, general ledger, autonomous final pricing, unrestricted code-changing agent, or custom payment processor unless a verified paid workflow requires it.
