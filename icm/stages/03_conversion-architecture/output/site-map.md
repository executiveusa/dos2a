# Stage 03 — Canonical site map

## Public
- `/` — five-second orientation + cinematic proof + primary conversion
- `/servicios` — service families, outcomes, planning guidance
- `/eventos` — corporate, agency, conference, launch, activation, stand/exhibition scenarios
- `/portafolio` — curated verified project proof
- `/casos/[slug]` — verified case stories only
- `/blog` — dos A Señal index
- `/blog/[slug]` — article/detail
- `/cotizar` — structured quote/event brief flow

## Public La Genio
La Genio is reachable from the home, services, events, portfolio/cases, and quote flow as a nontechnical concierge. It is not a generic `/chat` BYOK surface.

Primary entry labels:
- `Hablar con La Genio`
- `Cuéntale tu evento a La Genio`

## Owner/private
- `/inicio` — owner daily summary after authentication
- `/oportunidades` — interested people/companies and follow-up
- `/cotizaciones` — quote drafts and approvals
- `/proyectos` — active event/project operations
- `/contenido` — approved content/case workflow
- `/bienvenida` — interactive bilingual owner onboarding
- `/la-genio` — authenticated owner assistant

Public and owner navigation must be visually and permission-wise separate. A public visitor must never discover private business data through La Genio or predictable routes.
