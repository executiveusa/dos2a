# Stage 02 proposal — asset curation

## Objective
Turn the 82-image DOSA archive into a small, provenance-safe visual proof system for the cinematic site.

## Scope
Selection, classification, hashes, scene roles, derivative rules, and separate desktop/mobile art direction. No public UI change in this stage.

## Acceptance
- source archive count/dimensions recorded;
- top 10 selected with exact source filenames/hashes;
- legacy separators and concept renders flagged;
- six-scene reference map defined;
- desktop/mobile focal rules and performance derivative contract defined.
