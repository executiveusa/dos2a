# Stage 00 proposal — truth baseline

## Objective
Capture verified repository, production, claim, architecture, and risk truth before new product code is changed.

## Scope
Evidence/docs only. No runtime, dependency, database, authentication, or UI behavior change.

## Acceptance
- canonical master SHA recorded;
- production availability and current defects observed;
- deployed/parked surfaces distinguished;
- verified/owner-attested/unverified claims separated;
- risks and downstream mitigation stages recorded;
- zero-context handoff to Stage 01 exists.
